# Handle Worker Reports

- **DONE:** Inspect the result and required evidence before accepting it.
- **DONE_WITH_CONCERNS:** Evaluate the concern immediately. Resolve important behavior or scope problems; distinguish optional observations from acceptance blockers.
- **NEEDS_CONTEXT:** Supply available relevant information. Ask the user only for a material decision that cannot be resolved from code, documents, or conversation.
- **BLOCKED:** Identify whether the cause is missing context, environment/authority, plan defects, task shape, or technical difficulty. Change that cause before retrying. Use an existing capable worker, a fresh perspective, direct implementation, or a narrower assignment when useful and supported.

A worker's escalation deserves assessment, not an automatic model upgrade or another identical attempt. Keep actual authorization and workspace requirements intact.
