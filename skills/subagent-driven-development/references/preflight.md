# Check Dependencies Before Execution

For a complex or risky plan, inspect shared files, interfaces, and constraints before dispatching dependent work. Compare the expected producer/consumer behavior and any test assumptions with the real code.

Record concrete conflicts and material decisions in chat or an existing ledger. A pair-by-pair table for unrelated tasks is unnecessary. Resolve reversible choices from the requirements and existing patterns; ask only about material unresolved behavior, scope, or risk after checking available context. Do not treat the plan as authority to introduce a known defect or perform an unapproved Git action.
