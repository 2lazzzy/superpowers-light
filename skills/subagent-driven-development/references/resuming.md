# Resume From Recorded Progress

For long work or handoff, read the ledger's plan identity, decisions, completed scope, validation, and unresolved findings. Check those claims against the current source, Git status/history, and exact reviewed snapshot before resuming. A completion line alone does not prove the state still exists; local changes may be uncommitted, modified, or reverted.

Do not redo work that is already present and validated. Resume at the first genuinely incomplete dependency. If a ledger belongs to another plan, leave it intact and use the correct task record. Recover from both source state and available records; Git history cannot recover work that was never committed.
