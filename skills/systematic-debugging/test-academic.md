# Debugging Decision Checks

Use the current [SKILL.md](SKILL.md) to answer these questions. This is a reading check, not proof that a real bug was fixed.

1. What distinguishes a known cause that can receive a focused fix from an uncertain failure that needs investigation?
2. What evidence would discriminate between two plausible causes?
3. How should a failed hypothesis change the next action?
4. When can authorized incident mitigation precede complete diagnosis?
5. Why does a fixed count of failed attempts not prove an architectural problem?
6. What verification is appropriate for the original symptom and affected behavior?
7. Which tests should be retained by default, and when may explicitly temporary test artifacts be removed?
